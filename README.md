Простое офлайн-приложение для ведения дневника пикфлоуметрии. Для людей с бронхиальной астмой.

**Все данные хранятся только на вашем телефоне. Никаких серверов, аккаунтов, аналитики и рекламы.**

## ✨ Возможности

- 📊 **График** — две линии: до и после ингаляции
- 📈 **Цветовые зоны** (зелёная / жёлтая / красная) по личному рекорду
- 📝 **Заметки** к каждому замеру — кашель, одышка, самочувствие
- 📉 **Статистика** — среднее за неделю и месяц, тренд
- 🔔 **Напоминания** — утро и вечер, отдельные тумблеры и время
- ⏰ **Уведомление, если сегодня не было замера**
- 📄 **PDF-отчёт** для врача с графиком
- 💾 **Экспорт / импорт JSON** — бэкап и перенос между устройствами
- 🌗 **Material You** — цвета подхватываются из обоев (Android 12+)
- 🇷🇺 Интерфейс на русском языке

## 📱 Установка

### Способ 1: скачать APK (рекомендуется)

1. Откройте [последний релиз](https://github.com/Lolip-p/Asthma-Diary/releases/latest)
2. Скачайте файл `asthma-diary-vX.Y.Z.apk`
3. На телефоне разрешите установку из неизвестных источников:
   - **Настройки → Приложения → Специальный доступ → Установка неизвестных приложений → выберите ваш браузер / файловый менеджер → Разрешить**
4. Откройте скачанный APK → **Установить**

⚠️ Пока не опубликовано. См. раздел «F-Droid» ниже.

## 🚀 Как пользоваться

1. Делайте замер пикфлоуметром утром и вечером
2. На главном экране нажмите **«Добавить запись»**
3. Укажите:
   - **До** или **После** ингаляции
   - **Утро** или **Вечер** (определяется автоматически по времени, можно поменять)
   - **Значение** (шаг 25 л/мин, по умолчанию 400)
   - **Заметку** (опционально)
4. Сохраните — запись появится в списке и на графике

Через несколько дней увидите динамику и цветовые зоны.
